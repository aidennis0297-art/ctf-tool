# 🕵️ CTF & 방탈출 수사 메모장 (Windows 11 Notepad Edition)

Windows 11 다크 테마 메모장 기반의 **오프라인 CTF & 방탈출 결합형 수사 워크벤치 소프트웨어**입니다.
단 하나의 `.exe` 파일만으로 공유 및 배포가 가능하며, 외부 인터넷 연결이 차단된 환경에서도 100% 로컬 오프라인으로 작동합니다.

---

## ⚡ 빠른 시작 (Standalone EXE 실행)

### 🖥️ 단독 실행 파일 (`.exe` 만으로 즉시 실행)
* **`CTFNotepad.exe`** 또는 **`CTF-Notepad-Portable.exe`**를 더블 클릭하면 즉시 독립 창으로 실행됩니다.
* 다른 컴퓨터나 팀원에게 **이 `.exe` 파일 하나만 카카오톡, 디스코드, USB로 전송해도 100% 독립 실행**됩니다.
* 별도의 Node.js, Python 설치가 전혀 필요 없습니다 (Zero-Dependency).

### 🌐 브라우저 실행
* **`RUN_TOOLKIT.bat`** 또는 `index.html`을 더블 클릭하면 Chrome / Edge 브라우저에서도 즉시 열립니다.

## 🛠️ 주요 기능 둘러보기

### 1. 🕵️ 수사 추리 보드 (Investigation Board)
- **단서 칸반 보드**: [획득한 단서] ➔ [분석 중] ➔ [해결 완료] 3단계로 현장 단서 관리
- **🧩 조각 플래그 결합기 (Master Flag)**: 각 단서 카드에서 얻은 플래그 조각(`CTF{part1_`, `part2_`, `done}`)을 자동으로 결합해 최종 정답 완성
- **🔐 방탈출 자물쇠 도우미**:
  - **방향 자물쇠**: 상하좌우(⬆️⬇️⬅️➡️) 클릭 시 순차 번호(1234), 키패드 번호(8246), 영문(UDLR) 자동 변환
  - **아나그램 단어 풀이기**: 뒤섞인 영단어 철자 입력 시 빈출 키워드(escape, secret, cipher 등) 즉시 매칭
- **💾 1초 JSON 동기화**: [JSON 저장]을 눌러 파일로 내보낸 뒤, 팀원 노트북에서 [JSON 불러오기]를 누르면 수사 상황이 즉시 동기화됩니다.

### 2. 🔐 암호 & 만능 디코더 (Crypto Lab)
- **만능 실시간 변환기**: 텍스트를 입력하는 즉시 아래 규격으로 동시 변환:
  - Base64 (인코딩/디코딩)
  - 16진수 Hex (인코딩/디코딩)
  - 2진수 Binary (8비트 인코딩/디코딩)
  - URL 디코딩 (%20 복원)
  - ROT13 & ROT47
  - 아바시 (Atbash: A↔Z, B↔Y)
  - A1Z26 (A=1, B=2...)
  - 모스 부호 (Morse Code) 변환 및 **실제 소리(Beep) 재생** 🔊
- **시저(Caesar) 전수조사**: 1~25 시프트를 일괄 계산하고, `FLAG`, `KEY`, `PASS` 등 영단어가 포함된 결과를 초록색으로 자동 하이라이트
- **비제네르(Vigenère) 암호**: 암호화 및 복호화
- **단일 바이트 XOR 전수조사 (0x00 ~ 0xFF)**: 256개 모든 키로 XOR 연산 후, 영문 빈도수가 높은 추천 해독 문장 상위 정렬
- **베이컨 암호 (Baconian)**: A/B 5글자 이진 패턴 복호화
- **오프라인 해시 계산기**: MD5, SHA-1, SHA-256 계산

### 3. 🖼️ 스테고 & 미디어 연구소 (Steganography & Media Lab)
- **스마트폰 사진 보정기**: 어두운 방이나 UV(자외선) 잉크로 쓴 글씨를 읽을 수 있도록 명암 대비(Contrast), 색상 반전(Invert), 흑백 이진화(Thresholding) 필터 제공
- **오프라인 QR 코드 스캐너**: 이미지 파일 업로드나 `Ctrl+V` 붙여넣기 시 사진 속 QR 코드를 즉시 해독
- **🔬 비트 플레인 뷰어 (StegOnline 오프라인 대체)**: R, G, B, Alpha 채널의 최하위 비트(0번 LSB)부터 최상위 비트(7번 MSB)까지 캔버스 분해 및 LSB 텍스트 자동 추출
- **📍 EXIF 메타데이터 파서**: 카메라 기종, 촬영 일시, GPS 위도/경도, 사용자 코멘트 추출
- **🎵 오디오 스펙트로그램**: 음성 파일(WAV/MP3) 속에 숨겨진 고주파 그림이나 모스 부호 시각화

### 4. 🔍 포렌식 & 헥스 뷰어 (Forensics & Hex Lab)
- **파일 시그니처 (Magic Bytes) 판별**: 40여 가지 파일 포맷 헤더 내장. 확장자 위장 파일(예: `.txt`로 바꾼 `.zip`)을 즉각 탐지하여 빨간색 경고 표시
- **💾 내장 헥스 뷰어**: [Offset | Hex 바이트 | ASCII] 3분할 덤프 뷰어 및 바이트/문자열 검색
- **📝 Strings & 플래그 추출기**: 파일 내부의 모든 출력 가능 문자열을 추출하고, `FLAG`, `CTF`, `KEY`, `PASS` 원클릭 필터링
- **🧩 임베디드 파일 카빙**: PNG 이미지 뒤에 붙어있는 ZIP 압축파일 등 중첩된 파일을 감지하여 원클릭으로 추출 및 다운로드

### 5. 📖 실전 가이드 & 족보 (Strategy & Cheat Sheet)
- 3인 1팀 실전 롤플레이 매뉴얼 (수색러, 분석러, 추리러)
- 방탈출 자물쇠 / 도어락 빈출 패턴 10선
- 모스 부호 및 A1Z26 빠른 치트시트
- 단서가 막혔을 때 탈출 체크리스트

## 🐍 보조 Python CLI 도구 (`ctf_tool.py`)

파이썬 환경에서 대용량 파일(수십~수백 MB)을 고속으로 분석하거나 터미널에서 작업할 때 유용합니다. (파이썬 표준 라이브러리만 사용하므로 pip 설치 불필요)

```bash
# 1. 파일 매직 바이트 검사 및 위장 탐지
python ctf_tool.py magic secret.png

# 2. 파일 내부 문자열 및 FLAG 검색
python ctf_tool.py strings secret.bin -g flag

# 3. 단일 바이트 XOR 256개 키 전수조사
python ctf_tool.py xor "1b37373331363f78151b7f2b783431333d78397828372d363c78373e783a393b3736"

# 4. 이미지 뒤에 숨겨진 ZIP 등 카빙 추출
python ctf_tool.py carve stego_image.png

# 5. Base64 / Hex / 시저 일괄 자동 디코딩
python ctf_tool.py decode "KHOOR ZRUOG"

# 6. 같은 와이파이/핫스팟 팀원들이 스마트폰이나 노트북으로 접속할 수 있게 로컬 서버 열기
python ctf_tool.py serve --port 8000
```
